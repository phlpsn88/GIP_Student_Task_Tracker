
# 🧭 Fase 3 – Applicatieontwikkeling
## Periode: December – Januari - Februari - Maart

### 🎯 Doel
Een werkende **webapplicatie** bouwen met HTML, CSS, PHP en MySQL.

---

### 📋 Verwachtingen
- Homepage met uitleg over de diensten die de applicatie aan te bieden heeft.
- Login/Register pagina's aanmaken.
- Front-end maken (gebruiksvriendelijke webpagina’s).  
- Back-end programmeren in PHP met **OOP-principes**.  
- Databank koppelen via PHP (CRUD-operaties).  
- Wachtwoorden beveiligen (hashen).  
- Applicatie testen in lokale omgeving (XAMPP).

---

### 💡 Tips
- Werk in kleine stappen (eerst inloggen, dan taken).  
- Test elke module afzonderlijk.  
- Gebruik GitHub voor versiebeheer en een vlotte samenwerking.

---

### 🧰 Product(en)
- Werkende webapplicatie  
- Broncode op GitHub  
- Screenshots van kernfunctionaliteit  

---
